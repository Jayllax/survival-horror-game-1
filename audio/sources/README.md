# Original supplied recordings

These are the unmodified source takes supplied by the designer. Godot ignores this folder; runtime versions are in the neighboring audio folders.

- `forest_ambience.m4a`: converted to Ogg Vorbis because Godot does not import M4A/AAC directly.
- `concrete_footstep_take.wav`: original upload named `concrecte_footstep.wav`.
- `dirt_footstep_take.wav`: original stereo dirt-step recording.

The footstep takes were cut into six short variants each, downmixed to mono PCM16/48 kHz, peak-matched to -6 dBFS before playback volume, with 3 ms onset and 35 ms release fades. Music MP3s are unchanged and live only in `audio/music/`.
