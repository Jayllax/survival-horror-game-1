# Forest artwork

**21 objects × 3 colors = 63 native PNGs.** These are the game textures, with no enlarged export copies. One native pixel displays at 2×, matching the character and interior kit. Every object is horizontally symmetrical and uses `../ignotum.gpl`.

Place scenes from `scenes/objects/forest/` and choose **Color Variant** in the Inspector. Objects are passable until **Solid** is enabled. See the [forest kit guide](../../../docs/guides/FOREST_KIT_GUIDE.md) for placement, dimensions, collision, Pixilart editing and previews.
