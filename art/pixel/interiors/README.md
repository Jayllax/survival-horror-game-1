# Interior artwork

These **75 native PNGs** are the actual game assets: 24 objects × 3 colors, plus three stair textures shared by four stair layouts. There is no separate enlarged export copy. One native pixel is displayed at 2×, matching the character art.

Place their scenes from `scenes/objects/interiors/`, then choose **Color Variant** in the Inspector. See the [interior kit guide](../../../docs/guides/INTERIOR_KIT_GUIDE.md) for placement, lamps, stairs, editable pixel sizes and a catalog of the whole set.
