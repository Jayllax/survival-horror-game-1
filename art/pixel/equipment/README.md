# Equipment artwork

Four native PNGs: shotgun 32×10, buckshot shells 14×10, compact saw 18×12 and damage kit 14×14. These are the actual game textures, with hard transparency and colors from `../ignotum.gpl`; there are no enlarged duplicate sources.

New pickup scenes and the shotgun display these at 2×. The older handgun retains its existing PNG, size and pose. Weapon profiles expose hand, muzzle and flashlight positions; changing the shotgun's artwork scale does not enlarge its lights.

Edit these PNGs in Pixilart at 100%, keeping their dimensions. See the [weapon and upgrade guide](../../../docs/guides/WEAPONS_AND_UPGRADES.md).
